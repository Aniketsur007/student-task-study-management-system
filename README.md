# Student Task & Study Management System

## Project Overview

The **Student Task & Study Management System (STSMS)** is a proposed web-based application designed to help students organize their academic responsibilities in one place.

Students often manage assignments, study tasks, subjects, and deadlines using notebooks, messaging applications, calendars, or multiple productivity tools. This project aims to provide a simple centralized platform where students can manage their academic tasks and monitor their progress efficiently.

This repository currently contains the **Week 1 Project Planning and Requirements Analysis** documentation for the proposed system. The project is being planned as part of the **Junior Software Developer Intern** virtual internship.

## Project Objectives

The main objectives of the project are:

* Centralize academic tasks and assignments.
* Help students keep track of deadlines.
* Allow users to organize tasks according to subjects.
* Provide task priorities and completion statuses.
* Display upcoming, pending, completed, and overdue tasks.
* Provide a simple and responsive user interface.
* Maintain user data securely and reliably.
